Privacy

Your text and workbooks stay inside the browser.

Effective September 23, 2026

Text and files you process

Your pasted text, opened text files, and selected XLSX workbooks are read into browser memory. Small text inputs may be processed on the page; larger text and workbook operations may be processed by a Web Worker running inside the same browser tab. That content is not uploaded to RemoveDuplicates.org, sent to Cloudflare as part of a processing request, persisted by the site, or included in the page URL.

Browser storage and clearing your work

RemoveDuplicates.org does not save your input or result in cookies, local storage, session storage, IndexedDB, or an account. Close or refresh the tab to clear current text and workbook data from the page. Your browser and operating system may independently retain clipboard history, downloads, crash data, or temporary files according to their own settings.

File access and permissions

When you choose or drop a supported text file or XLSX workbook, your browser grants this page access only to the selected file so it can be read locally. The site does not request access to your camera, microphone, location, contacts, or notifications.

Results and downloads

Text results and cleaned workbooks are generated in browser memory. A cleaned workbook is offered as a new download; RemoveDuplicates.org does not write back to or overwrite the selected original. Review warnings, matching choices, and the downloaded copy before replacing or relying on source material. Your browser or operating system controls where downloads are saved and how long they remain there.

Analytics, advertising, and third parties

RemoveDuplicates.org does not use analytics scripts, advertising pixels, social widgets, tracking cookies, third-party fonts, or behavioral profiles. The page does not send your text or workbook contents to an external API.

Cloudflare request data

Cloudflare delivers and protects this website. Like other hosting networks, it may process basic HTTP request data such as your IP address, browser and device headers, requested path, timestamps, and security events. This is page-delivery and abuse-prevention data; it does not include the text or workbook contents you process.

Optional AI agent endpoint

RemoveDuplicates.org also offers a Model Context Protocol endpoint at /mcp for AI agents and developer tools; the website pages never call it. Text an agent chooses to send there is processed in memory only to return the cleaned result for that single request. The application does not store or log that text, and the endpoint does not accept XLSX workbooks. Cloudflare delivers and protects those requests as described above.

Retention and your choices

RemoveDuplicates.org has no server copy of your text or workbook contents to retain, inspect, or delete. Cloudflare may retain request and security records under its own operational policies. Only process content you are authorized to handle on your device, especially when using a shared or managed computer.

Changes

If the service's data practices change, this page and its effective date will be updated before the new practice applies.
